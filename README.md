# 实验一  基于文件系统的“商城库存管理”应用系统

## 一、目录结构

```
lab1/
├── src/inventory.cpp      C++ 源程序（全部功能实现）
├── Makefile               编译脚本
├── inventory              可执行程序（make 生成）
├── data/
│   ├── products.txt        商品目录（主数据）
│   └── records.txt         进销记录（流水数据，只追加）
├── report/
│   ├── run_demo.py         自动演示脚本：驱动程序完成全部功能并录制会话
│   ├── render_transcripts.py  把录制的会话渲染成“截图”(PNG)
│   ├── fill_report.py      把实验结果与总结写回实验报告 Word 文档
│   ├── transcripts/        录制的会话纯文本
│   └── screenshots/        生成的截图，用于实验报告
└── 实验一 基于文件系统的商城库存管理系统.docx   实验报告（已填写）
```

## 二、编译与运行

```bash
make                # 编译，生成可执行文件 inventory
make init           # 生成一套演示数据集（15 种商品 + 175 条进销记录）
make run            # 运行系统（交互式菜单）
```

也可直接使用：

```bash
g++ -std=c++17 -O2 -Wall -Wextra src/inventory.cpp -o inventory
./inventory --init      # 重新生成演示数据集
./inventory             # 启动程序
```

## 三、数据文件格式

两个文件都是纯文本，每一行是一条记录，字段之间用 `|` 分隔，
因此可以直接用文本编辑器查看，也便于用 `head` / `wc` 等命令检查。

`data/products.txt`（商品目录，每行一条）：

```
商品编号|商品名称|类别|单价|库存量
P1001|智能手机 A1|手机数码|2999.00|9
```

`data/records.txt`（进销记录，每行一条，只追加）：

```
记录号|商品编号|商品名称|操作类型|操作人|操作时间|操作数量|单价
1004|P1001|智能手机 A1|S|王五|2026-03-04 02:17:49|16|2999.00
```

其中操作类型 `P` 表示进货、`S` 表示销售。

## 四、功能与菜单对照

| 菜单 | 功能 | 实验要求 |
| --- | --- | --- |
| 1 | 商品目录查看（按类别组织） | 商品目录查看 |
| 2 | 进货（增加库存并写进销记录） | 库存管理（进货） |
| 3 | 销售（减少库存并写进销记录） | 库存管理（销售） |
| 4 | 删除商品（保留其进销记录） | 商品删除 |
| 5 | 按类别浏览商品（按库存量排序） | 按类别浏览与库存排序 |
| 6 | 进销记录查询（时间范围 / 操作人） | 进销记录查询 |
| 7 | 销量汇总（全部商品或某类商品） | 销量汇总 |
| 8 | 新增商品 | 数据集维护（附加） |

## 五、数据关联与校验

* **关联**：进销记录通过“商品编号”关联到商品目录中的商品，
  同时把“商品名称 / 单价”冗余保存在记录里，
  因此商品被删除后，它的历史进销记录仍然可以完整读出。
* **校验**：商品编号必须存在、数量必须为正整数、销售数量不得超过当前库存、
  时间必须符合 `YYYY-MM-DD HH:MM:SS` 且年月日时分秒都在合法范围内、
  字段中不允许出现分隔符 `|`。

## 六、重新生成实验报告

```bash
python3 report/run_demo.py            # 录制演示会话（会先重置数据集）
python3 report/render_transcripts.py  # 渲染截图
python3 report/fill_report.py         # 填写 Word 实验报告
```
